安裝「跡錄」

TraceCam・運動錄影疊加：即時地圖、速度、距離、海拔，拍完免後製

手機掃描 QR Code

用手機相機掃描，開啟本頁後按上方「一鍵安裝」。

https://mathedu-prog.github.io/tracecam/install.html
直接開啟

iPhone／iPad（Safari）

iOS 僅有 Safari 能加入主畫面；若在其他瀏覽器開啟，請先複製連結改用 Safari。

  1. 在 Safari 開啟上方網址，點選工具列的分享圖示（方框加向上箭頭）。
  2. 在選單中往下滑，點選加入主畫面。
  3. 確認名稱「跡錄」，點右上角新增。
  4. 從主畫面開啟，首次請允許相機、麥克風與定位（建議選「使用 App 期間」）。
錄影完成後，在行程詳情點「儲存／分享影片」→ 選擇「儲存視訊」即可存入相簿。

Android（Chrome）

  1. 用 Chrome 開啟上方網址。
  2. 點選右上角⋮選單。
  3. 選擇安裝應用程式（部分機型顯示為「加到主畫面」），再點安裝。
  4. 從桌面或應用程式列表開啟，並允許相機、麥克風與定位權限。

電腦（Chrome／Edge）

  1. 用 Chrome 或 Edge 開啟上方網址。
  2. 點選網址列右側的安裝圖示（螢幕加向下箭頭）。
  3. 在彈出視窗按安裝，即可像一般軟體從桌面或開始選單開啟。
電腦沒有 GPS，定位會以網路估算，僅適合預覽介面；實際運動請使用手機。

安裝後可離線開啟。有新版本時，App 內會出現「有新版本可用．立即更新」。
